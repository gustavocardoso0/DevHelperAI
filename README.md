Nome do Projeto: <Strong>DevHelperAI</strong>
<BR>
Projeto desenvolvido com linguagens JavaScript, SQL, o framework ReactJS e API da OpenAI.
<BR>
DevHelperAI foi projetada para estudantes de tecnologia a esclarecer dúvidas e aprimorar habilidades. Ele é integrando diretamente com o ChatGPT para proporcionar uma experiência de usuário interativa e eficiente. A ideia central do projeto é utilizar essa aplicação em escolas e faculdades afim de permitir que os usuários estudem, utilizando perguntas e recebam respostas em tempo real, enquanto todas as interações são armazenadas na página do usuário e isso ocorre de maneira segura em um banco de dados MySQL.
