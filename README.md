Nome do Projeto: <Strong>DevHelperAI</strong>
<BR><BR>
Projeto desenvolvido com linguagens JavaScript, SQL, o framework ReactJS e API da OpenAI.
<BR><BR>
"DevHelperAI" - Projeto Final do 3º Semestre, na Universidade São Judas Tadeu, SP.
<BR><BR>
DevHelperAI foi projetada para estudantes de tecnologia a esclarecer dúvidas e aprimorar habilidades. Ele é integrando diretamente com o ChatGPT para proporcionar uma experiência de usuário interativa e eficiente. A ideia central do projeto é utilizar essa aplicação em escolas e faculdades afim de permitir que os usuários estudem, utilizando perguntas e recebam respostas em tempo real, enquanto todas as interações são armazenadas na página do usuário e isso ocorre de maneira segura em um banco de dados MySQL.
<BR><BR>
Funcionalidades Principais:
Integração com ChatGPT: Respostas automatizadas e inteligentes para perguntas dos usuários.
Armazenamento Seguro: Todas as perguntas e respostas são registradas no banco de dados MySQL.
Interface Intuitiva: Facilita a interação dos usuários com o sistema.
<BR><BR>
Tecnologias Utilizadas:
Backend: Node.js com Express para a criação da API.
Frontend: React para a construção de uma interface de usuário dinâmica.
Banco de Dados: MySQL para armazenamento e gerenciamento eficiente dos dados.
Integração de APIs: Uso do ChatGPT para processamento de linguagem natural e geração de respostas.
<BR><BR>
Objetivo do Projeto:
O objetivo principal do DevHelperAI é oferecer uma ferramenta que vá além das funcionalidades tradicionais, proporcionando uma interface interativa e inteligente que auxilie os usuários a esclarecer dúvidas e aprimorar habilidades de tecnologia.
